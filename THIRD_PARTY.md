# Third-party material

- Sentence embeddings: [sentence-transformers/all-MiniLM-L6-v2](https://huggingface.co/sentence-transformers/all-MiniLM-L6-v2), Apache-2.0; downloaded as the Xenova ONNX export. FAISS provides the local similarity index. Model files are excluded from Git and downloaded by setup_models.py.

- Kokoro model: [hexgrad/Kokoro-82M](https://huggingface.co/hexgrad/Kokoro-82M), Apache-2.0. ONNX files are downloaded from [kokoro-onnx releases](https://github.com/thewh1teagle/kokoro-onnx/releases); URL and SHA-256 are recorded in `.cache/model_manifest.json`. Models are not committed.
- Noto Sans and Noto Sans Devanagari: Google Fonts, SIL Open Font License; notices accompany fonts under `assets/fonts/`.
- Somaiya logos: extracted from the user's supplied ODT. Institutional marks remain their owners' property. The project code's licence does not grant trademark rights.
- Somaiya knowledge text: official website/document excerpts with URLs, dates and source hashes. Original owners retain copyright. Corpus inclusion is for this academic project and does not represent institutional endorsement.
- Supplied media: every image/video must include its source and permission/licence in the input CSV. Identifiable people require a consent file.
- Motion graphics and music: generated by this code; music contains no third-party samples. Stock neural speech is not a real-person voice clone.
- FFmpeg is an external prerequisite; its build-specific licensing applies. Python package licences apply independently; install via requirements.txt rather than redistributing the virtual environment.
- Optional Edge TTS uses an external service with its own terms and availability; it is not an offline guarantee.


## Optional Pixabay video footage

Downloaded only when configured for general, unbranded videos. Each run records source pages, contributors, asset hashes and the current Pixabay Content License summary in `stock_sources.json` and `CREDITS.md`. Licence: https://pixabay.com/service/license-summary/ . Additional third-party rights may apply. Stock is visibly marked illustrative. Standalone downloaded clips are excluded from submission ZIPs; they are not part of this codebase's licence. API search responses are cached for 24 hours.


## Optional local AI illustration stills

- Image model: [stabilityai/sd-turbo](https://huggingface.co/stabilityai/sd-turbo), Stability AI Community License (July 5, 2024). Free for research and non-commercial use, which covers this academic project; commercial use requires free registration with Stability AI and is limited to organisations under USD 1M annual revenue. Run locally on the user's GPU through Hugging Face `diffusers`; no API and no cost.
- Depth model: [depth-anything/Depth-Anything-V2-Small-hf](https://huggingface.co/depth-anything/Depth-Anything-V2-Small-hf), Apache-2.0. Used only to estimate depth for parallax.
- Weights are downloaded once by `scripts/setup_illustration.py` into `~/.cache/agentreel/models` (outside the repo and never committed); `illustration_models.json` there records the snapshot revision and licence files.
- Every generated image is recorded in the run's `assets/manifest.csv` and `illustrations.json` with prompt, seed, model and SHA-256, logged in `run_log.jsonl` at zero cost, and labelled "AI-GENERATED IMAGE" on screen. Prompts are screened against unsafe terms; storyboard rules forbid real or named people, recognisable likenesses, trademarked characters and logos.

## Optional local image-to-video

- [Wan-AI/Wan2.2-TI2V-5B-Diffusers](https://huggingface.co/Wan-AI/Wan2.2-TI2V-5B-Diffusers), Apache-2.0. Default on GPUs with 20 GB or more.
- [Lightricks/LTX-Video-0.9.5](https://huggingface.co/Lightricks/LTX-Video-0.9.5), LTX-Video 0.9.5 Open Weights License (licence file shipped in the repository and recorded by the setup script). Used on 12-20 GB GPUs.
- Both run locally through Hugging Face `diffusers`; no API and no cost. Weights are downloaded once by `scripts/setup_video.py` into `~/.cache/agentreel/models` (outside the repo); `video_models.json` there records the snapshot and licence files.
- Each clip starts from an AgentReel illustration still, so its manifest licence records both the video model and the still's image-model licence. Clips are labelled "AI-GENERATED VIDEO" on screen.
- Extra Python dependencies for these pipelines: `ftfy` (Wan prompt cleaning) and `sentencepiece` (T5 tokenizers), pinned in `requirements-gpu.txt`.
